# PowerShell Scripting

A collection of PowerShell scripts developed while learning Windows administration, system management, and cybersecurity.

## About This Repository

This repository documents my practical learning journey with PowerShell. It contains scripts designed to explore Windows environments, automate administrative tasks, and understand system and Active Directory operations.

## Scripts

### 1. Quick Recon (`quick-recon.psm1`)

A PowerShell module containing basic reconnaissance-related functions.

**Focus areas:**

- PowerShell functions
- Script modules
- Module imports and exports
- Active Directory reconnaissance concepts

### 2. Headless ('headless.ps1')
A powershell script that I made to enable me log in to my VMs headlessly faster. Saves time and memory resources
